# Bidora

**Bidora** is a full-stack online auction marketplace where users will be able to create auctions, discover products and place bids.

The project is being rebuilt as a modern, production-style web application.

## Current progress

The current focus is the frontend and homepage experience.

Implemented so far:

- Responsive Bidora UI and branding
- Responsive navigation
- Hero section
- Search and category filtering with demo data
- Reusable auction cards
- Responsive auction grid
- shadcn/ui component integration

## Technologies

## Planned features

- User registration and login
- Create and manage auctions
- Product images and categories
- Real-time bidding
- Live auction countdowns
- Search, filtering and sorting
- Favourites / watchlist
- User profiles and bidding history
- Winner selection when an auction ends
- Online payments
- Notifications
- Responsive and animated UI

## Goal

The goal is to build Bidora as a realistic full-stack marketplace while gaining hands-on experience with modern frontend development, backend APIs, databases, real-time communication, security and deployment.

# Bidora Frontend

Frontend for **Bidora**, a modern online auction marketplace.

## What has been implemented

- Responsive homepage
- Responsive navbar and mobile menu
- Bidora brand colors and custom styling
- Hero section
- Auction search and category filter UI
- Reusable auction cards
- Demo auction filtering
- Responsive auction grid
- shadcn/ui integration
- Mobile-first responsive design

## Technologies

- **Next.js 16**
- **React**
- **TypeScript**
- **Tailwind CSS v4**
- **shadcn/ui**
- **Lucide React**

# Bidora Frontend

Frontend for **Bidora**, a modern online auction marketplace.

## Implemented

- Responsive homepage
- Responsive navbar with mobile menu
- Custom Bidora branding and styling
- Hero section
- Auction search and category filtering with demo data
- Reusable auction cards
- Responsive auction grid
- Popular categories section
- How Bidora Works section
- Seller CTA and footer
- Explore All Auctions page
- Dynamic auction details page
- Sell Auction page
- Auction creation form
- Form validation with React Hook Form and Zod
- Image preview for auction uploads
- Login page
- Registration page
- Show / hide password functionality
- Editable user profile
- Profile navigation
- Favourites page
- My Bids page
- My Auctions page
- Responsive layouts for desktop, tablet and mobile
- shadcn/ui integration

## Technologies

- **Next.js 16**
- **React**
- **TypeScript**
- **Tailwind CSS v4**
- **React Hook Form**
- **Zod**
- **shadcn/ui**
- **Lucide React**

## Current Status

The frontend foundation is mostly complete.

Some functionality currently uses demo or placeholder data and will be connected to the Bidora backend API.
